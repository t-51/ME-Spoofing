1. Introduction

This Privacy Policy explains how ME Spoofing ("we", "our", or "the app") treats user data and privacy. We are committed to maintaining the highest standard of user privacy. ME Spoofing is designed as a privacy-first, zero-logging userspace proxy tool.

2. No Collection of Personal Data (Zero-Log Policy)

Zero-Logging Guarantee: We do not collect, store, monitor, inspect, or sell any personal information, browsing history, visited websites, DNS records, or transmitted payload data.

ME Spoofing operates as a local userspace proxy (binding to 127.0.0.1). All traffic modification (such as TCP fragmentation and decoy SNI injection) is processed strictly in-memory on your local device. No network traffic is transmitted to or analyzed by any servers owned or operated by the developer.

4. Android Device Permissions

The application requests only permissions essential for its core functionality:

Permission Purpose
INTERNET Allows the proxy engine to relay outbound network requests to user-defined destinations.
ACCESS_NETWORK_STATE Detects network connection status (Wi-Fi, Cellular) to handle reconnections seamlessly.
POST_NOTIFICATIONS Displays an ongoing foreground notification while the proxy is running (required on Android 13+).
FOREGROUND_SERVICE
(DATA_SYNC / SPECIAL_USE)		 Maintains the active proxy service in the background so connections are not terminated while using other apps.
REQUEST_IGNORE_BATTERY_OPTIMIZATIONS Prompted optionally so aggressive device battery managers do not interrupt background proxy sessions.
RECEIVE_BOOT_COMPLETED Allows optional automatic restart of the proxy service after device boot if configured by the user.

Note: ME Spoofing does not require Android's VpnService permission as it operates strictly as an in-device userspace socket proxy.
