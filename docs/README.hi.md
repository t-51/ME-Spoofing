## 📖 परिचय

**ME Spoofing** एक उन्नत और उच्च-प्रदर्शन यूजरस्पेस प्रॉक्सी रिले और डीप पैकेट इंस्पेक्शन (DPI) बाईपास इंजन है, जिसे **MHPanel** के लिए विकसित किया गया है। यह बहु-स्तरीय ट्रांसपोर्ट प्रोटोकॉल — TCP फ्रैग्मेंटेशन, डिकॉय SNI इंजेक्शन और Cloudflare Anycast IP फ्रंटिंग — के माध्यम से इंटरनेट प्रतिबंधों को सुरक्षित रूप से बायपास करता है, बिना किसी VPN अनुमति या सिस्टम-स्तरीय विशेषाधिकार के।

---

## 🏗️ आर्किटेक्चर और Google Play अनुपालन (VpnService के बिना)

पारंपरिक VPN ऐप्स के विपरीत, **ME Spoofing Android की `VpnService` API का उपयोग नहीं करता**:

| विशेषता | विवरण |
|---|---|
| **कोई सिस्टम VPN प्रोफ़ाइल नहीं** | OS-स्तरीय ग्लोबल रूटिंग टेबल नहीं बदलता, कोई TUN वर्चुअल इंटरफ़ेस नहीं बनाता |
| **शुद्ध यूजरस्पेस लोकल रिले** | इंजन केवल `127.0.0.1:<पोर्ट>` पर बाइंड करता है, एक बुद्धिमान फॉर्वर्डर के रूप में |
| **100% Google Play नीति अनुपालन** | VPN ऐप्स पर Google Play प्रतिबंधों से पूरी तरह मुक्त |
| **यूनिवर्सल क्लाइंट सपोर्ट** | Happ, v2rayNG, Npv Tunnel, Sing-box, Telegram और ब्राउज़र के साथ संगत |

## 🚀 दो ट्रांसपोर्ट मोड

### मोड 1 — डायरेक्ट SNI स्पूफिंग और TCP फ्रैग्मेंटेशन (पोर्ट 15443)

MHPanel एज नोड्स से सीधा कनेक्शन, जिसमें:
- **TLS ClientHello का माइक्रोसेकंड-स्तरीय फ्रैग्मेंटेशन** — TCP रिकॉर्ड सीमाओं के पार
- **डिकॉय फेक SNI इंजेक्शन** — DPI फायरवॉल को धोखा देने के लिए विश्वसनीय डोमेन नाम इंजेक्ट किए जाते हैं
- अधिकांश नेटवर्क के लिए उपयुक्त जहां मुख्य सर्वर IP पहुंच योग्य है

### मोड 2 — Cloudflare Clean IP ट्रांसपोर्ट (पोर्ट 443)

सभी ट्रैफिक को स्वच्छ, अनब्लॉक किए हुए **Cloudflare Anycast IP पतों** के माध्यम से रूट करता है:
- **डायनामिक SNI रीराइटिंग और फ्रैग्मेंटेशन** — ISP-स्तरीय SNI-आधारित फ़िल्टरिंग को रोकता है
- **Anycast IP फ्रंटिंग** — ट्रैफिक फॉर्वर्ड होने से पहले Cloudflare के वैश्विक नेटवर्क तक पहुंचता है
- उपयुक्त जब MHPanel का मुख्य सर्वर IP ब्लॉक हो

## ⚡ मुख्य विशेषताएं

### 📊 लाइव कनेक्शन लॉग (फ़िल्टर करने योग्य)

रियल-टाइम स्ट्रीमिंग लॉग व्यू, चार फ़िल्टर टैब के साथ:
- **सभी** — हर प्रॉक्सी इवेंट
- **फेक इंजेक्शन** — SNI स्पूफिंग और डिकॉय SNI इंजेक्शन इवेंट
- **फ्रैग्मेंट** — TCP फ्रैग्मेंटेशन इवेंट
- **त्रुटियां** — कनेक्शन त्रुटियां और चेतावनियां

### 📡 लाइव नेटवर्क आंकड़े

होम स्क्रीन पर रियल-टाइम नेटवर्क मेट्रिक्स:
- **डाउनलोड स्पीड** (लाइव, प्रति सेकंड)
- **अपलोड स्पीड** (लाइव, प्रति सेकंड)
- **सक्रिय एक साथ कनेक्शन** की संख्या

### 🔀 रूटिंग असिस्टेंट डायलॉग

एक स्मार्ट कॉन्फिग कन्वर्जन टूल:
1. अपना मौजूदा V2Ray / Xray JSON कॉन्फिग पेस्ट करें
2. असिस्टेंट इसे `127.0.0.1:<पोर्ट>` को अपस्ट्रीम के रूप में उपयोग करने के लिए रीराइट करता है
3. उपयोग के लिए तैयार कॉन्फिग **plus** लोकल ट्रैफिक के लिए bypass रूटिंग नियम आउटपुट करता है
4. परिणाम को सीधे Happ, v2rayNG, Sing-box या Npv Tunnel में पेस्ट करें

### ⏱️ स्मार्ट टाइमर और रिवॉर्ड सिस्टम

- टाइमर **केवल सक्रिय कनेक्शन के दौरान काउंटडाउन करता है** — डिस्कनेक्ट होने पर तुरंत रुकता है
- नेटवर्क रुकावट के दौरान अनुचित समय की खपत को रोकता है
- **4 घंटे का बोनस रिवॉर्ड** विज्ञापन देखने के माध्यम से उपलब्ध

## 📱 सेटअप गाइड

### चरण 1: APK इंस्टॉल करें

[GitHub Releases](https://github.com/t-51/snispoof/releases) से नवीनतम APK डाउनलोड करें और इंस्टॉल करें।

### चरण 2: ट्रांसपोर्ट मोड चुनें

| परिदृश्य | अनुशंसित मोड |
|---|---|
| सर्वर IP पहुंच योग्य है | मोड 1 — SNI फ्रैग्मेंटेशन |
| सर्वर IP ब्लॉक है | मोड 2 — Cloudflare Clean IP |

### चरण 3: कनेक्ट करें

1. ऐप खोलें और **कनेक्ट** पर टैप करें
2. प्रॉक्सी `127.0.0.1:<कॉन्फिगर किया गया पोर्ट>` पर उपलब्ध होगा
3. अपने पसंदीदा क्लाइंट (Happ, v2rayNG, आदि) को इस प्रॉक्सी पते का उपयोग करने के लिए कॉन्फिगर करें

### चरण 4: रूटिंग असिस्टेंट का उपयोग करें (वैकल्पिक)

यदि आपके पास मौजूदा V2Ray/Xray कॉन्फिग है:
1. होम स्क्रीन पर **रूटिंग असिस्टेंट** आइकन पर टैप करें
2. अपना कॉन्फिग JSON पेस्ट करें
3. कन्वर्ट किया गया कॉन्फिग कॉपी करें — किसी भी समर्थित क्लाइंट में उपयोग के लिए तैयार
