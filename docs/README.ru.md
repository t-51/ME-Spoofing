## 📖 Обзор

**ME Spoofing** — высокопроизводительный локальный прокси-движок и инструмент обхода систем глубокой инспекции пакетов (DPI), разработанный для **MHPanel**. Приложение обеспечивает устойчивый обход блокировок благодаря многослойным транспортным протоколам — TCP-фрагментации, подмене SNI и IP-фронтингу через Cloudflare Anycast — без необходимости VPN-разрешений или системных привилегий.

---

## 🏗️ Архитектура и соответствие правилам Google Play (Без VpnService)

В отличие от классических VPN-приложений, **ME Spoofing не использует API `VpnService` Android**:

| Свойство | Подробности |
|---|---|
| **Без системного VPN-профиля** | Не изменяет глобальные таблицы маршрутизации ОС и не устанавливает виртуальный TUN-интерфейс |
| **Локальный прокси в пространстве пользователя** | Движок слушает исключительно на `127.0.0.1:<порты>` как интеллектуальный ретранслятор |
| **100% соответствие правилам Google Play** | Полностью свободно от ограничений Google Play для VPN-приложений |
| **Универсальная поддержка клиентов** | Happ, v2rayNG, Npv Tunnel, Sing-box, Telegram, браузеры |

## 🚀 Два режима передачи данных

### Режим 1 — Прямое подключение и фрагментация SNI (Порт 15443)

Прямое соединение с серверами MHPanel с:
- **Микросекундной фрагментацией TLS ClientHello** через границы TCP-записей
- **Подменой SNI-домена** — внедрение доверенных имён для обхода DPI-систем
- Оптимален для большинства сетей, где основной IP-адрес сервера доступен

### Режим 2 — Транспорт Cloudflare Clean IP (Порт 443)

Маршрутизация всего трафика через чистые незаблокированные **Cloudflare Anycast IP**:
- **Динамическая перезапись SNI с фрагментацией** — защита от SNI-фильтрации на уровне провайдера
- **Anycast IP-фронтинг** — трафик проходит через глобальную сеть Cloudflare перед пересылкой
- Оптимален при блокировке основного IP-адреса MHPanel

## ⚡ Ключевые возможности

### 📊 Живые логи подключений (с фильтрами)

Потоковый просмотр логов в реальном времени с четырьмя вкладками фильтрации:
- **Все** — все события прокси
- **Поддельное внедрение** — события подмены SNI и внедрения ложного SNI
- **Фрагментация** — события TCP-фрагментации
- **Ошибки** — ошибки подключения и предупреждения

### 📡 Живая статистика сети

Метрики сети в реальном времени на главном экране:
- **Скорость загрузки** (live, каждую секунду)
- **Скорость отдачи** (live, каждую секунду)
- Количество **активных одновременных соединений**

### 🔀 Помощник по маршрутизации

Умный инструмент конвертации конфигурации:
1. Вставьте существующий V2Ray / Xray JSON-конфиг
2. Помощник перепишет его для использования `127.0.0.1:<порт>` как upstream
3. Выдаёт готовый конфиг **плюс** правила bypass-маршрутизации для локального трафика
4. Вставьте результат напрямую в Happ, v2rayNG, Sing-box или Npv Tunnel

### ⏱️ Умная система времени и наград

- Таймер **считает только при активном подключении** — мгновенно останавливается при разрыве
- Предотвращает несправедливое расходование времени при нестабильной сети
- **Бонус 4 часа** доступен за просмотр рекламы

### 🔄 Проверка обновлений в реальном времени

- Проверяет GitHub Releases на наличие новых версий по запросу
- Доступно через **иконку колокольчика** в заголовке приложения
- Показывает краткое содержание changelog доступного обновления

### 🔧 Динамическое управление портами

- Добавление, изменение и удаление любого количества локальных портов прослушивания в настройках

### 🎨 Тёмная / Светлая тема

- Автоматически следует настройке ОС тёмный/светлый режим
- Переопределяется вручную в настройках приложения

### 🌍 Поддержка 10 языков

Полная поддержка RTL и LTR: **Русский, Персидский, Английский, Арабский, Китайский, Испанский, Итальянский, Немецкий, Французский, Хинди**  
Автоматическое определение языка системы при первом запуске.

## 📱 Руководство по настройке

### Шаг 1: Установка APK

Скачайте последний APK из [GitHub Releases](https://github.com/t-51/snispoof/releases) и установите.

### Шаг 2: Выбор режима транспорта

| Ситуация | Рекомендуемый режим |
|---|---|
| IP-адрес сервера доступен | Режим 1 — Фрагментация SNI |
| IP-адрес сервера заблокирован | Режим 2 — Cloudflare Clean IP |

### Шаг 3: Подключение

1. Откройте приложение и нажмите **Подключиться**
2. Прокси доступен на `127.0.0.1:<настроенный порт>`
3. Настройте предпочтительный клиент (Happ, v2rayNG и т.д.) на использование этого адреса

### Шаг 4: Использование помощника по маршрутизации (Опционально)

Если у вас есть существующий V2Ray/Xray конфиг:
1. Нажмите иконку **Помощника по маршрутизации** на главном экране
2. Вставьте JSON-конфиг
3. Скопируйте конвертированный конфиг — готов к использованию в любом поддерживаемом клиенте
